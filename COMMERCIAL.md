# Commercial model

Qualock is designed as an open-core developer tool.

## Open-source core

This repository is Apache-2.0 licensed and is intended to remain useful without a hosted account. The open-source core includes the CLI, canary format, local qualification runner, evidence model, deterministic policy engine, and local reports.

## Potential commercial products

Commercial offerings may add managed qualification runners, scheduled release checks, private canary storage, organization policies, audit history, dashboards, enterprise authentication, managed credential isolation, priority support, and other team or hosted capabilities.

Those services are not required to use the open-source CLI locally.

## Licensing boundary

Code in this repository is governed by Apache-2.0. Proprietary services or extensions, if introduced, will live outside this repository or be clearly identified under separate terms. The Apache license does not grant trademark rights.

For now, Qualock is pre-1.0 and the commercial surface is intentionally not part of the v0.1 product contract.
